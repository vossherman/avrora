Wayland Linux Dmabuf Unstable V1 Protocol, version unstable v1, version 3





The linux dmabuf protocol is a way to create dmabuf-based wl_buffers


Used in the Qt Wayland Compositor


The sources can be found in qtwayland/src/3rdparty/wayland/protocols/linux-dmabuf/linux-dmabuf-unstable-v1.xml.
