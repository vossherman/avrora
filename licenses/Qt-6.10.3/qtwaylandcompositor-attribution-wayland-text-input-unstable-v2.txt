Wayland Text Input Protocol v2, version unstable v2





Adds support for text input and input methods to applications.


Used in the Qt Wayland Compositor, and the Qt Wayland platform plugin.


The sources can be found in qtwayland/src/3rdparty/wayland/protocols/text-input/v2/text-input-unstable-v2.xml.
