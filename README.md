## Запуск

1. Скопируй **всю папку** релиза в доступный для записи каталог. При получении архива сначала распакуй его.
2. Для локальной проверки открой **«Тестовый клиент.exe»**. Данные входа уже заполнены; нажми «Войти». Рабочий сервер не используется, тестовые изменения исчезают после закрытия.
3. Для своего аккаунта открой **«Запустить Аврору.exe»**, введи логин и пароль.
4. **«Проверить сборку.exe»** проверяет контрольные суммы файлов, зависимости и вход на локальный мок-сервер.

Не перемещай отдельные файлы из `app`, `core`, `bin` или `runtime`. EXE-кнопки используют встроенный в Windows .NET Framework 4.x. Сборка не подписана цифровым сертификатом; если запуск запрещён политикой организации, согласуй его с администратором.

## Работа с JSON

1. Выбери работу → **«Выгрузить в JSON → Загрузки»**. Для навыка используй формат **«Обмен (json-decisions)»**. «Полная копия» предназначена для резервной копии.
2. Отредактируй экспортированный файл или подготовь его по `skills/arm-student-json/SKILL.md`.
3. Выбери ту же работу → **«Загрузить из JSON…»** → проверь список изменений.
4. Задай длительность: `0` — сразу, `1,5` — полторы минуты. При положительной длительности доступны синтетические нажатия `sendKBE` со случайными интервалами.
5. Нажми **«Отправить на сервер»**. До начала записи подготовку можно отменить. Во время записи дождись ответа сервера.

Меняются редактируемые поля, код и присутствующее в JSON поле `test-input`. Описания метода и алгоритма пересобираются автоматически. Статус «Сдано» доступен только для просмотра. Копия исходной работы перед импортом поможет восстановить данные вручную.

После сообщения **«Сервер подтвердил сохранение»** команды записи приняты. Автоматического перечитывания и сверки нет; результат можно проверить отдельным открытием работы.

## Навык `arm-student-json`

Приложи в ИИ-чат **`skills/arm-student-json/SKILL.md`**, текст задания и JSON-шаблон, экспортированный из нужной работы. Пример запроса:

> Используй приложенный SKILL.md. Заполни JSON по заданию, сохрани структуру шаблона. После JSON отдельно выведи таблицу тестов: вход, ожидаемый вывод, что проверяется.

Сохрани **только JSON-блок**, без Markdown-разметки, в файл `.json` в UTF-8. Таблица тестов остаётся отдельно и автоматически не импортируется. Проверь код и ожидаемые результаты: навык может ошибаться. Сам клиент навык не запускает.

## Управление и данные

- **Ctrl++ / Ctrl+=**, **Ctrl+−** — масштаб; **Ctrl+0** — 100%. Настройка сохраняется, процент плавно исчезает.
- Пароль сохраняется через Windows DPAPI в `%LOCALAPPDATA%\AuroraClient`. «Показать пароль» меняет видимость; **«Выйти» удаляет сохранённые данные**, закрытие окна — сохраняет.
- На том же Windows-профиле могут подставиться ранее сохранённые данные клиента. В папку релиза пароли не включены. Масштаб общий для обычного и тестового запуска.
- JSON сохраняется в папке `Downloads` текущего пользователя. Журнал находится внизу окна. Отчёт проверки — `%LOCALAPPDATA%\AuroraClient\release-v01-check.txt`.

## Если не запускается

- Запусти «Проверить сборку.exe» и посмотри указанный отчёт.
- Отсутствующие DLL обычно означают неполное копирование папки. Скопируй комплект целиком.
- Для рабочего сервера проверь доступность сети и завершение другого клиента с тем же аккаунтом.
- При ошибке записи сначала проверь состояние работы; повторный импорт без проверки может перезаписать уже сохранённые изменения.
